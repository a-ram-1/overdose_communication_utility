### Code and data for "Overdose-related communication in Connecticut: reported receipt, perceived utility, and responses among overdose prevention and response professionals"

The survey can be accessed [here](https://yalesurvey.ca1.qualtrics.com/jfe/form/SV_1TT2xyabKh2wPiK). If you have questions please reach out to a.ram@yale.edu. 

Files include: 

* ct\_overdose\_survey\_responses\_toshare.csv: Deidentified survey data
* overdose_survey_analysis.xlsx: Aggregation for all response categories
* od\_survey\_analysis.rmd: The rest of my analysis, and how I produced all my figures
* overdose\_survey\_report.pdf: The raw survey report from Qualtrics using response percentages
